The fp32 ONNX export used by the local AI loader is 29,541,096 bytes and SHA-256 pinned as `bb7189b2523b8485d9dd6baa2e7e8bccce4493760daa33ffcd432f667945bf62` in browser-watermark-removal 0.1.1. Its fallback order is app-local `models/migan.onnx`, `https://huggingface.co/lxfater/inpaint-web/resolve/main/migan.onnx`, then `https://hf-mirror.com/lxfater/inpaint-web/resolve/main/migan.onnx`. This app does not include or use that repository's editor code.

Privacy and network behavior
AI inference runs in the user's browser. The application sends no photo pixels, masks, OCR text, or edited output to a server. On first AI use, the browser downloads the public MI-GAN model from Hugging Face (with hf-mirror.com as fallback); the model is cached locally by the AI library when browser storage permits. ONNX Runtime Web and its WebAssembly files are bundled as this app's assets.
